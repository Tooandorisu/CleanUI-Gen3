# Clean UI – Gen 3

A clean, modern look for the menus of **Pokémon FireRed, LeafGreen, Ruby, Sapphire and Emerald** in Gen1Recomp. The game world, battles and sprites stay as they are; the menus, text boxes and windows on top of them are redrawn in a simple, readable style that fits phones and big screens alike.

Clean UI only changes how things look. It doesn't change any game logic, so you can turn it off at any time and your save is untouched.

## Download

Get the latest `CleanUI-Gen3-vX_Y_Z.zip` from [Releases](https://github.com/Tooandorisu/CleanUI-Gen3/releases) and install it in Gen1Recomp like any other mod (OPTIONS → MODS, or the mod manager). It needs a recent Gen1Recomp dev build.

Each release is the normal build. A `-DEBUG` build (with an on-screen overlay that shows what Clean UI is doing) is sometimes shared for testing — you don't need it for playing.

## Options

Found under OPTIONS → MODS → Gen3 Clean UI:

| Option | What it does |
|---|---|
| **DARK MODE** | Dark colours for all clean menus. |
| **FIT TO SCREEN** | Turn on if the game's own menus show around the edges of the clean ones on your device. |

## What's clean

**Everywhere**
- Title screen, NEW GAME / CONTINUE, options and naming
- START menu (also in the Safari Zone, with MODS added)
- Text boxes, YES/NO and list choices
- Mod manager and mod option pages
- Text codes like `{PLAYER}` and button symbols are filled in

**Pokémon**
- Party (including choosing a Pokémon for Day-Care, trades, move tutors and mail), summary pages, stat growth
- Pokémon sprites everywhere they fit, shiny ones shown as shiny
- Status and Pokérus badges

**Items**
- Bag (all pockets, moving items, selling), TM Case, Berry Pouch, Pokéblock case
- Poké Mart buying and selling
- PC: item storage, box storage (wallpapers, party drawer, moving items, box switching), mailbox

**Battle**
- FIGHT / BAG / POKéMON / RUN menu, moves, Safari Zone menu, double battles
- HP boxes with HP and EXP bars, gender, status badges and the "caught" marker
- Battle text

**FireRed / LeafGreen**
- Pokédex (list, entry, habitat pages), Trainer Card, Town Map and FLY map, Fame Checker, Teachy TV

**Ruby / Sapphire / Emerald**
- Pokédex (list, entry, size page, SEARCH and START menu), Trainer Card, region map and FLY map
- PokéNav: main menus, CONDITION search and condition page, Match Call, Ribbons list

Translation mods work: names, items, moves and descriptions come from the game, so they show in the translated language. Clean UI's own headings are in English.

## Still the original look

Some screens still use the game's own graphics, among them the Move Relearner, evolution and egg hatching scenes, the Day-Care list, Match Call calls on the field (Emerald), the Hall of Fame, contests, Secret Bases, the Battle Frontier and link/Union Room screens. These are on the list for later versions.

## Works with

- **Cleaner Mod Options** – the clean mod list follows its filters.
- Mods that add START menu entries (DexNav, GameShark and others) – their entries show in the clean START menu.
